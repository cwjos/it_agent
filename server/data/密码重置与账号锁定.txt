# 密码重置与账号锁定处理指南

## 一、Windows 本地账户密码忘记
**方法**：
1. 使用密码重置磁盘（若之前创建过）：插入磁盘，点击“重置密码”即可。
2. 借助管理员账户：登录其他管理员账户（如内置 Administrator 未禁用），在“计算机管理” → “本地用户和组”中重置该用户密码。
3. 使用 Windows 安装 U 盘，进入修复模式，通过命令提示符替换粘滞键（sethc.exe）为 cmd.exe，重启后按 Shift 键弹出命令提示符，使用 `net user 用户名 新密码` 重置。
   - 具体步骤：从 U 盘启动 → 修复计算机 → 疑难解答 → 命令提示符 → 输入 `copy c:\windows\system32\sethc.exe c:\` 备份 → 输入 `copy c:\windows\system32\cmd.exe c:\windows\system32\sethc.exe` 覆盖 → 重启，在登录界面连按 5 次 Shift 键，弹出管理员 cmd，执行 `net user 用户名 密码`。

---

## 二、域账号锁定或密码过期
**现象**：登录时提示“账户已锁定，请与管理员联系”或“密码已过期，请重置”。

**解决**：
1. 联系域管理员解锁账户（通常管理员可通过 Active Directory 用户和计算机工具解锁）。
2. 自助重置（如果公司配置了 SSPR，即自助密码重置门户）：
   - 访问公司指定的密码重置页面，通过手机验证或安全问题重置。
3. 修改过期密码：
   - 按 Ctrl+Alt+Delete → “更改密码”，输入旧密码和新密码。
   - 若无法进入系统，可在登录界面点击“其他用户”，使用“忘记密码”链接（需配置）。

## 三、第三方应用账号锁定（如 Office 365、企业邮箱）
1. 访问公司内网门户，使用“忘记密码”功能，通过备用邮箱或手机号重置。
2. 若账户被锁定（多次错误尝试），通常等待 15-30 分钟自动解锁，或联系 IT 人工解锁。
