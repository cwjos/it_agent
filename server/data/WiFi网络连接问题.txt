# WiFi 网络连接故障排查手册

## 一、无法搜索到任何 WiFi 信号
**可能原因**：
- 无线网卡被禁用或驱动故障。
- 物理开关（Fn+Fx）关闭。
- 路由器关闭了 SSID 广播。

**解决**：
1. 检查无线网卡是否启用：网络和共享中心 → 更改适配器设置 → 右键“无线网络连接” → “启用”。
2. 检查设备管理器中无线网卡是否有黄色感叹号，若有则更新或重装驱动。
3. 确认笔记本电脑的无线物理开关已打开。
4. 使用手机检查路由器是否正常广播，若手机也搜索不到则问题在路由器（重启或检查设置）。

## 二、连接 WiFi 后提示“无法连接到此网络”或“受限”
**常见原因**：
- 密码错误。
- IP 地址冲突。
- 路由器 DHCP 地址池耗尽。
- 无线信号干扰或距离过远。

**排查步骤**：
1. **验证密码**：在另一设备输入相同密码测试，或登录路由器管理界面查看密码。
2. **释放/续租 IP**：
   - 以管理员身份运行 `ipconfig /release` 后，再执行 `ipconfig /renew`。
   - 如果卡住，可手动设置静态 IP（同网段，如 192.168.1.100）。
3. **重启路由器**：拔掉电源 30 秒后重新插上。
4. **更换信道**：登录路由器，将无线信道从“自动”改为固定（如 6 或 11），避免干扰。
5. **忘记网络并重连**：点击“忘记此网络”，重新搜索输入密码。

---

## 三、WiFi 信号满格但网速极慢
**可能原因**：
- 相邻 WiFi 信道干扰。
- 路由器连接设备过多。
- 网线或光猫故障。

**优化**：
- 使用 5GHz 频段（若路由器支持），避免拥挤的 2.4GHz。
- 登录路由器管理界面，查看“连接设备列表”，断开陌生设备。
- 调整路由器位置（尽量居中、远离金属障碍物）。
- 检查网线是否完好，尝试更换路由器网口。
- 用 `ping 192.168.1.1 -t` 观察内网延迟，若延迟突然升高则可能是路由器负载过高。

---

## 四、WiFi 频繁掉线
**解决**：
1. 更新无线网卡驱动（从官网下载最新版本）。
2. 在设备管理器中，无线网卡属性 → 电源管理 → 取消“允许计算机关闭此设备以节约电源”。
3. 路由器设置中，关闭“WiFi 自动断开”功能，并调整“信标间隔”和“RTS 阈值”。
4. 若使用双频合一，建议关闭，分别设置 2.4G 和 5G 不同的 SSID。
