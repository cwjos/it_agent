# Outlook 邮件问题全攻略

## 一、Outlook 显示“已断开”或“需要密码”
**现象**：状态栏显示“已断开”，或频繁弹出密码输入框。

**可能原因**：
- 邮箱密码过期或已更改。
- 服务器地址配置错误。
- 网络代理阻止连接。
- 身份验证方式不匹配。

**解决步骤**：
1. **更新密码**：
   - 通过网页登录邮箱确认密码正确，如为 Office 365 且启用 MFA，需生成“应用密码”并在 Outlook 中输入。
2. **检查服务器地址**：
   - 打开“文件” → “帐户设置” → “帐户设置”，双击邮箱账户。
   - 确保服务器地址正确（如 IMAP：imap.office365.com，SMTP：smtp.office365.com；Exchange：outlook.office365.com）。
3. **关闭代理**：临时关闭所有代理软件，并检查 Windows 代理设置（设置 → 网络和 Internet → 代理）。
4. **重建配置文件**：
   - 控制面板 → 邮件 → 显示配置文件 → 新建配置文件，添加邮箱账户，设为默认。
5. **修复 Office**：运行“控制面板” → “程序和功能” → 右键 Office → “更改” → “快速修复”。

## 二、能收邮件但不能发送
**现象**：接收正常，发送时提示“发件服务器(SMTP)要求验证”或“无法连接到 SMTP 服务器”。

**常见原因**：
- SMTP 认证未开启。
- SMTP 端口被阻断（25 端口被 ISP 封锁）。
- 发件服务器地址错误。

**解决方案**：
1. 在账户设置的“更多设置”中，切换到“发送服务器”选项卡，勾选“我的发送服务器(SMTP)要求验证”，并选择“使用与接收服务器相同的设置”。
2. 修改 SMTP 端口：
   - 常用端口：587（推荐，支持 TLS）、465（SSL）、25（明文，常被封）。
   - 在“高级”选项卡中，将发送端口改为 587，加密方式选“STARTTLS”或“TLS”。
3. 确认 SMTP 服务器地址与接收服务器一致（如均为 smtp.office365.com）。
4. 若使用企业 Exchange，尝试启用“选中连接安全性（SSL）”。

## 三、Outlook 卡顿或频繁崩溃
**现象**：打开缓慢、频繁未响应，或突然关闭。

**可能原因**：
- 数据文件（PST/OST）过大（>20GB）。
- 加载项冲突。
- 损坏的配置文件或系统文件。

**解决**：
1. **压缩数据文件**：在 Outlook 中右键邮箱根 → “数据文件属性” → “高级” → “Outlook 数据文件设置” → “压缩”。
2. **禁用加载项**：以安全模式启动 Outlook（Win+R → `outlook /safe`），若正常则逐项禁用加载项（文件 → 选项 → 加载项 → 转到 → 取消勾选）。
3. **修复 PST 文件**：使用 ScanPST.exe（位于 Office 安装目录）扫描修复。
4. **重建索引**：关闭 Outlook，删除搜索索引（Windows 搜索设置 → 高级索引选项 → 修改 → 取消 Outlook 索引再重新添加）。

## 四、邮件附件无法打开或发送
**现象**：附件图标不显示，无法下载，或发送时提示“附件大小超出限制”。

**处理**：
1. 检查附件大小是否超过邮件服务器限制（通常 20-25MB），若超出则使用云盘链接替代。
2. 在 Outlook 选项中取消“压缩图片”功能（文件 → 选项 → 高级 → 图像大小和质量 → 勾选“不压缩图片”）。
3. 尝试将附件保存到本地再打开，或将文件重命名（去掉特殊字符）。
