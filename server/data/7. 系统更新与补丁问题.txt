# Windows 系统更新与补丁故障处理

## 一、Windows Update 无法检查更新（错误代码 0x8007000E 等）
**现象**：点击“检查更新”后出现错误，或长时间卡在“正在检查更新”。

**可能原因**：
- 系统文件损坏。
- 更新服务（Windows Update）未运行。
- 磁盘空间不足。
- 网络连接问题（代理、DNS）。

**解决步骤**：
1. **运行 Windows 更新疑难解答**：设置 → 更新和安全 → 疑难解答 → 其他疑难解答 → Windows Update → 运行。
2. **重启更新服务**：
   - `services.msc` 中找到 Windows Update 服务，右键重启。
   - 同时重启 Background Intelligent Transfer Service (BITS) 和 Cryptographic Services。
3. **清理更新缓存**：
   - 停止 Windows Update 服务。
   - 删除 `C:\Windows\SoftwareDistribution\Download` 目录下所有文件。
   - 重启服务，再次检查更新。
4. **手动下载补丁**：访问 Microsoft Update Catalog（catalog.update.microsoft.com），输入 KB 编号下载安装。
5. **使用 DISM 修复系统映像**：
   - `DISM /Online /Cleanup-Image /RestoreHealth`
   - 完成后执行 `sfc /scannow`。

---

## 二、更新后系统蓝屏或无法启动
**处理**：
1. 进入安全模式，卸载最近安装的更新：
   - 设置 → 更新和安全 → Windows Update → 查看更新历史记录 → 卸载更新。
   - 选择最新的更新项并卸载。
2. 使用系统还原回退到更新前状态。
3. 若无法进入系统，可使用 Windows 安装介质进入“修复计算机” → “疑难解答” → “高级选项” → “卸载最近的更新”。
4. 更新驱动程序，特别是显卡和网卡驱动，它们常与系统更新冲突。

---

## 三、更新下载缓慢或反复失败
**优化**：
- 更改“传递优化”设置：设置 → Windows 更新 → 高级选项 → 传递优化 → 选择“从本地网络和 Internet 上的电脑下载”，限制带宽。
- 使用有线网络代替 WiFi。
- 确保系统盘（C 盘）有至少 8GB 可用空间。
- 检查第三方杀毒软件是否阻止更新，可临时禁用。
