# 硬件故障排查与性能优化

## 一、电脑无法开机（无反应、无显示）
**排查步骤**：
1. 检查电源线连接是否牢固，插座供电正常。
2. 台式机：检查电源按钮是否卡住，可断开电源长按开机键 30 秒放电。
3. 笔记本：长按电源键 10-15 秒强制重启；若电池可拆卸，则拔掉电池仅用电源适配器测试。
4. 查看指示灯：若电源灯亮但屏幕无显示，可能是显示器信号线松脱或屏幕故障，可外接显示器测试。
5. 若风扇转但无显示，可能是内存或显卡接触不良，重插内存条（台式机）。

## 二、电脑运行异常缓慢
**常见原因**：
- 内存不足（RAM 使用率 > 90%）。
- 硬盘（尤其是机械硬盘）性能瓶颈。
- 后台程序过多，包括自启动软件。
- 系统碎片化或临时文件堆积。

**优化方法**：
1. **禁用不必要的启动项**：任务管理器 → 启动 → 禁用高影响项。
2. **增加内存**（若 <8GB，建议升至 16GB）。
3. **升级固态硬盘（SSD）**：将操作系统安装在 SSD 上，可极大提升读写速度。
4. **磁盘清理**：运行磁盘清理工具，删除临时文件、回收站文件等。
5. **优化虚拟内存**：设置于 SSD 上，大小建议为物理内存的 1.5 倍。
6. **关闭视觉效果**：系统属性 → 高级 → 性能设置 → 调整为“最佳性能”。

## 三、硬盘故障（坏道、异响）
**现象**：文件打开缓慢、频繁死机、听到“咔咔”声。

**处理**：
1. **立即备份重要数据**！若无法读取，使用 WinPE U 盘启动并复制数据。
2. 使用磁盘检查工具：右键磁盘 → 属性 → 工具 → 检查 → 扫描并修复。
3. 使用第三方工具如 CrystalDiskInfo 检查硬盘健康状态（S.M.A.R.T.），若显示“警告”或“不良”，应尽快更换硬盘。
4. 更换硬盘后，需重新安装操作系统和驱动。

## 四、风扇噪音大或散热不良
**解决**：
- 清理灰尘：用压缩空气吹散热器、风扇叶片（需断电）。
- 检查风扇转速是否异常（BIOS 中可查看）。
- 若风扇轴承干涩，可滴入少量润滑油（需拆机）。
- 改善通风环境，避免放置在软垫或封闭空间。
- 笔记本可增加散热垫或更换导热硅脂。
