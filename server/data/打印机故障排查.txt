# 打印机故障排查与维护指南

## 一、打印机显示“脱机”
**现象**：打印队列中任务停滞，打印机状态显示“脱机”。

**排查步骤**：
1. **检查硬件连接**：
   - 确保打印机电源开启，数据线（USB/网线）已稳固连接。
   - 对于网络打印机，用 `ping [打印机IP]` 测试网络连通性。
2. **取消“脱机使用打印机”**：
   - 打开“设备和打印机”，右键单击打印机 → “查看正在打印什么” → 在菜单栏点击“打印机” → 取消勾选“脱机使用打印机”。
3. **重启 Print Spooler 服务**：
   - 按 `Win + R`，输入 `services.msc`，找到“Print Spooler”服务，右键“重启”。
4. **重新添加打印机**：
   - 删除原打印机，然后点击“添加打印机”，按向导重新安装驱动。

---

## 二、打印乱码或输出空白
**现象**：打印出大量无意义字符，或纸张空白。

**原因**：
- 打印机驱动不匹配或损坏。
- 数据线传输干扰。
- 字体缺失或文件格式问题。

**解决**：
1. **更新驱动程序**：访问打印机官网下载对应操作系统版本的最新驱动，卸载旧驱动后重装。
2. **使用通用驱动**：如无法找到专用驱动，可尝试“Microsoft IPP 类驱动程序”或“HP 通用打印驱动”。
3. **打印测试页**：在打印机属性中点击“打印测试页”，如果正常则说明驱动基本可用，问题可能在于应用程序（如 Excel 格式不兼容）。
4. **更换 USB 线缆**或更换端口（USB 2.0/3.0）。

---

## 三、打印机卡纸
**现象**：纸张卡在进纸口、出纸口或内部。

**处理流程**：
1. 关闭打印机电源。
2. 小心取出所有可见纸张，注意不要撕裂。
3. 打开打印机后盖（如有），检查内部滚筒区域是否有碎纸片。
4. 使用镊子或专用工具取出残留纸屑。
5. 重新通电，按“取消”或“继续”按键清除错误状态。
6. 若经常卡纸，可能是搓纸轮磨损，需更换搓纸轮或清理纸路。

---

## 四、网络打印机无法找到
**现象**：添加打印机时搜索不到网络打印机，即使 IP 地址已知。

**解决**：
1. 确认打印机和电脑在同一子网（IP 地址前三段相同）。
2. 检查打印机是否开启 WSD（Web Services on Devices）服务，或启用 SNMP 协议。
3. 手动添加：选择“按 IP 地址添加打印机”，输入打印机 IP 和端口号（通常 9100）。
4. 若防火墙启用，需放行端口 9100（TCP）和 161（UDP，SNMP）。
5. 重启打印机和路由器。

---

## 五、打印速度极慢
**可能原因**：
- 打印机设置为“高质量”模式。
- 驱动程序启用了“双向通信”或“高级打印选项”。
- 网络带宽不足。

**优化**：
- 在打印机首选项中，将打印质量调至“标准”或“草稿”。
- 关闭“高级打印功能”（如水印、手动双面打印等）。
- 使用有线连接代替无线。
