# 共享文件夹访问故障排除

## 一、无法访问网络共享（提示“无法访问，您可能没有权限”）
**可能原因**：
- 账户没有访问该文件夹的权限。
- 工作组或域不匹配。
- 防火墙阻止了 SMB 协议（端口 445）。
- 共享主机未开启“网络发现和文件共享”。

**解决**：
1. **检查账户权限**：
   - 在共享主机上，右键文件夹 → “属性” → “共享” → “高级共享” → 确认“共享此文件夹”已勾选，并在“权限”中添加用户/组（如 Everyone 或域用户）。
2. **启用网络发现**：
   - 控制面板 → 网络和共享中心 → 更改高级共享设置 → 开启“网络发现”和“文件和打印机共享”。
3. **确认工作组/域**：
   - 检查两台电脑的工作组是否一致（计算机属性 → 更改设置 → 工作组）。
4. **防火墙设置**：
   - 确保入站规则中允许“文件和打印机共享（SMB-In）”通过防火墙。
5. **使用 IP 地址访问**：在资源管理器地址栏输入 `\\192.168.x.x\共享名称` 绕过 DNS 解析问题。

---

## 二、访问共享时提示“网络名不再可用”或“找不到网络路径”
**常见原因**：
- 共享主机进入了睡眠或待机状态。
- 主机 IP 地址变化（DHCP 续租）。
- SMB 服务版本不兼容（如旧版 Windows 可能只支持 SMB 1.0，而新版默认禁用）。

**处理**：
1. 唤醒共享主机，或将其电源选项设为“从不睡眠”。
2. 在共享主机上固定 IP 地址，或使用静态 DNS 记录。
3. 启用 SMB 1.0 支持（不推荐安全，但可临时测试）：
   - 控制面板 → 程序和功能 → 启用或关闭 Windows 功能 → 勾选“SMB 1.0/CIFS 文件共享支持”，重启。
4. 确保共享主机防火墙允许 ICMP（ping），便于测试连通性。

---

## 三、需要密码但输入密码无效
**可能原因**：
- 密码过期或账户被锁定。
- 使用的是本地账户而非 Microsoft 账户。
- 系统要求使用“网络凭据”而非本地密码。

**解决**：
1. 尝试使用 `.\用户名`（本地账户）或 `域\用户名`（域账户）登录。
2. 在共享主机上，为当前用户重新设置密码。
3. 检查共享主机是否启用了“密码保护的共享”，若关闭则无需密码。
